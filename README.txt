YOUR EMAIL ARCHIVE

Open index.html in your browser to browse and search your mail.
No installation, server, account, or internet connection is needed.

Contains 480 emails and 271 attachment files.
All Emails.txt combines all message headers and text, newest first.
Forwarded email text is included. Binary attachment contents are not transcribed.
Keep the attachments folder next to index.html for downloads to work.

Search matches full message text, subjects, senders, recipients, labels,
and attachment filenames. Separate words are combined (all must match);
put an exact phrase in double quotes. Searches ignore case and accents.
Type a sender name or email in the sender box to filter messages;
the dropdown shows the first six matching senders. Select a name for
an exact sender match. Use the arrow keys and Enter, or click a name.
Sender, sidebar label, and date filters can be combined.
Click Export beside the filters to save every email in the current view
as one text document, including results beyond the visible page.
The date filters use the calendar date in each original message header.

Use the sidebar to select All mail, Inbox, Sent, Archived, Trash, or a label.
Read status and stars are saved in this browser when local storage is available.
They only affect this local copy. The original MBOX is unchanged.
Text view shows search highlights. Formatted view keeps safe email formatting;
remote images and active email content are blocked. Inline images are files.
Your mail stays on your computer; the page has no external dependencies.

Keyboard: / or Cmd/Ctrl+K to search; J/K for next/previous email;
Escape to leave a field or close a message on a small screen.

To rebuild from the original MBOX:
  python3 "source/build_archive.py"
